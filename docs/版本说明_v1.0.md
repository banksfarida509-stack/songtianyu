# AI 招聘副驾 v1.0（筛选与回复建议版）

2026-10-19 基于 v0.9.13 修改。旧版完整备份在桌面：`hragentOS_旧版v0.9.13_备份`（文件夹）和 `hragentOS_旧版v0.9.13_备份.zip`。

## 保留

| 页面 | 功能 |
|---|---|
| 推荐人才 | 读取页面已加载的简历卡片 → 后台按岗位规则初筛 → 卡片下显示「推荐 / 待确认 / 不推荐 · 分数 · 理由」；面板按分数列出推荐的人，点一下定位到卡片；可选按哪个岗位规则初筛 |
| 聊天 | 你打开的会话里候选人发来新消息时，自动生成回复建议（意图、参考资料、护栏和平台拦截规则两道检查）；按钮：**复制 / 填入输入框 / 换一条 / 我已发送 / 不回复** |

发送永远由你自己点平台的「发送」按钮。

## 去掉

| 功能 | 原来怎么做 |
|---|---|
| 按推荐顺序打招呼、持续打招呼 | 插件模拟点击卡片上的「打招呼」 |
| 加载更多候选人 | 插件自动滚动页面、点「加载更多」 |
| 全自动回复 / 直接发送 | 插件往输入框分段打字并点「发送」 |
| 巡检未读会话 | 插件每 15 秒自动点开下一个未读会话 |
| 主动跟进（打招呼未回 / 已读不回） | 插件自动打开会话并发送跟进 |
| 自动发面试邀约、自动要附件简历 | 插件点平台按钮、填弹窗 |
| 采集历史约聊 | 插件依次自动点开最近 30 个会话 |
| 保持消息页常开 | 后台每 30 秒检查，自动新开并固定消息页 |
| 卡住自动刷新、自动更新后刷新页面 | 插件刷新招聘页面 |

双重保险：页面脚本 `inject.js` 只接受「读取 / 诊断 / 填入输入框」三种指令，其余一律拒绝；旧函数还在文件里但不会被调用。

## 安装

1. Chrome 打开 `chrome://extensions`，打开右上角「开发者模式」。
2. 如果装着旧版「AI 招聘副驾」，先点「移除」。
3. 点「加载已解压的扩展程序」，选择：
   `桌面\hragentOS_新版v1.0_筛选与回复建议\hr-agent\extension`
4. 刷新智联招聘页面。面板标题栏显示「推荐页 · 初筛」或「聊天页 · 回复建议」即为新版。

**注意：不要从管理后台“设置 → 下载插件”下载**，那里给的仍是服务器上的旧版 v0.9.13。

## 需要知道的

- 后台“设置 → 约聊回复方式”里的「全自动」开关对 v1.0 不起作用（插件忽略），但如果团队里还有人装着旧版插件，那台电脑仍会按开关全自动发送。建议在后台把全自动总开关关掉。
- 「填入输入框」是插件往平台的输入框里写字（不点发送）。如果担心平台检测，就只用「复制」，自己粘贴。
- 服务器端代码没有改动，也没有重新部署。
